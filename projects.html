Rbxl Flow-Free Recreation

A game that allows players to practice flow-free puzzles for another popular Roblox game known as "Forsaken". The game is entirely coded in luau, uses multi-script architecture, and its own data-management system.


Although the game's code and asset organization is, with honesty, quite scattered and hard to manage, this project taught me why its important to organize projects, make documentation, use tools to operate codebases, and how to deal with data issues affecting thousands of people in real time.

Rbxl Audio Engine

A module made for the automatic configuration of audio objects in Roblox. In 2024, a new Audio API was released that utilized linear routing through wires instead of just sound properties. This system requires a lot of manual configuration, so to make creation and manageability of audio objects easier, the module was made to automatically wire, parent, and group all audio objects in a rbxl project, whether they are two or three dimensional. It also features functionality to convert the legacy rbxl sound objects from 2006 to the modern system without any extra effort from the developer.
